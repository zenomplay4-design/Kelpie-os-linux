# Kelpie OS Linux

Projeto de ISO Live instalável baseado em Debian 13 (Trixie), GNOME e amd64.

## Versões
- V1: protótipo inicial do sistema e da automação de build.
- V2: identidade escura com detalhes cobre, pata no painel, wallpaper de constelação canina, aplicativos essenciais, Flatpak/Flathub, Bluetooth, impressão e pacotes de suporte NVIDIA. Consulte [VERSAO-2.md](VERSAO-2.md).

## Compilação
A compilação remota é feita pelo GitHub Actions. Abra a aba Actions e acompanhe o workflow **Build Kelpie OS ISO**. A ISO só será considerada pronta após o workflow concluir com sucesso, o artefato ser baixado e a imagem passar por verificação e teste de boot.
