# Kelpie OS Linux

Projeto de ISO Live instalável baseado em Debian 13 (Trixie), GNOME e amd64.

A compilação remota é feita pelo GitHub Actions. Consulte `README-GITHUB.txt` e execute o workflow **Build Kelpie OS ISO** na aba Actions.

A ISO só será considerada pronta após o workflow concluir com sucesso e o artefato ser validado.
